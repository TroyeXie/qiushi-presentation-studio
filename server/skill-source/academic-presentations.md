# 学术汇报：文献、数据与实验问题

适用于论文阅读、公共数据再分析、组会与课题设计。只加载本任务需要的部分；不是要求每次额外完成系统综述或重新运行全部数据。

## 从科学问题组织，而不是从文件夹组织

明确一个当前最有依据的主要问题；尚不成熟的方向以一两页盘点或备份呈现。章节名用“研究依据”“数据分析”“拓展探索”“实验模型”等听众可理解的名称，具体名称由任务决定。不要在正文用D01、D02等私有编号代替期刊、年份和研究身份。

开头用可编辑表格列出实际使用的论文、期刊、年份和数据源。列名使用“论文名”“期刊”“年份”“数据源”“主要内容”等，不重复堆砌“资料索引/机制索引/原始资料”。长表可按主题分成相邻页面；题名保留原文，按本页重点加粗有限关键词。广泛检索不等于所有文献都要进入正文。

## 对文献做三向核查

1. **知识**：原文已证明什么？实验体系、疾病、物种和主要Figure是什么？避免只扫描数据登录号。
2. **数据**：是否有可复用矩阵、供者/样本注释、Source Data或仅方法补表？复用同一数据的不同论文不是独立队列。
3. **增量**：本项目到底重复了作者主要结果，还是完成另一比较、来源核对或模型选择？三者可以有价值，但不能互称。

只声称实际阅读/运行的范围。摘要检索、相关段落核查、逐图精读、表格复算和全流程复跑分别记录。没有公开完整数据时说明现有资料层级，不从二手摘要补造实验。

## 原文页面的标准组合

一页围绕一个命题，用真实Figure支撑。可采用左图右文或两组并列：

- **标题**：核心对象/受体 + 具体疾病或细胞体系 + 清楚结果。
- **文献证据**：交代操作和实际读出，不只写“ECM来源影响活化”。应说明是哪种组织、何种状态的ECM、作用于哪类细胞。
- **图下注释**：一句最短但完整的结论，靠近图片，与图片水平中心一致。
- **可进一步探索的问题**：具体未知或本项目能增加的比较，不用“本次承接/不是凭空迁移”等说明性口号。
- **页底来源**：完整题名、期刊、年份。

默认不在正文额外写“Fig.X（PDF第N页局部）”，这些信息放备注和私有素材索引。原图已有的panel标签、标尺、图例和统计不可裁掉。非连续原文局部可并列，不能制造它们原本连续的印象。论文截图不重新排成相似原件。

模型、机制和功能名词首次出现时给出中文/英文全称及缩写；核心分子多时单独一页简介，写清配体、受体亚基、完整受体或作用蛋白的角色。中英文名称不能靠字面臆造。

## 引用排版与点击范围

固定文本结构：

- 原文图：`完整论文题名 | 期刊, 年份.`
- 本项目再分析：`数据来源：完整论文题名 | 期刊, 年份.`
- 官方项目：`官方来源：资料题名 | 机构或平台, 年份/核查日期.`

“数据来源：”和“官方来源：”按适用类型使用重点色加粗。期刊/机构名加粗、无下划线；**仅该名称本身链接到相应DOI或官方页面**。题名、竖线、标点、年份、Reviewed Preprint/v2等状态不得落在点击区域。多人/多论文引用分别有正确目标，不把一个链接套住全框。

在Office Open XML中使用独立文字run添加链接，并检查 `a:hlinkClick`、`a:hlinkMouseOver` 和形状级点击动作。仅改变可见文字颜色不能缩小点击范围。

来源完整、链接范围有限、字号统一并不矛盾。引用框向底部停靠，最后一行与页码底部形成视觉对齐，为页码留出右侧空间。不能将长引用逐页缩成不同字号。

原论文版本、在线年份、卷期年份需采用统一有依据的口径；Reviewed Preprint和正式发表不混同。官方计划说明资助方、牵头机构、平台与时间，不将研究目标写成完成结果。未获取真实网页截图时可保留来源明确的摘要，但不称为“网页截屏”。

## 数据图服务于一个具体判断

保留实际数据尺度和重复单位。在图内/图注给出会改变理解的信息，简单散点不再重复长句解释“点是样本”。复杂共同检出、互斥组合或不同加权量则必须明确。

- 来源图先覆盖实际分析范围，再按明确规则精简正文；完整结果保留备份。选定几类细胞中的最高表达不等于全器官最大分泌贡献。
- 配对供者比较优先保留连线和个体点；跨研究看研究内偏向与整体趋势，不强行校正到相同百分比。
- 气泡图写清面积是检出率、颜色是含零均值还是阳性均值，是否按基因缩放。UMAP不是组织空间图。
- 多子图用A–F等字母，按阅读顺序编号；同量纲适当共用坐标和图例。基因/蛋白名是否斜体服从当前规范，不因重绘自动改变。
- 非显著结果若直接影响假说，应进入正文；不把非显著称为“没有效应”或“已存在学术争议”。
- 热图采用明确选择规则和色标；原文Figure样式是参考，不是为模仿而重新筛样本、改P值或藏阴性结果。
- 配体—受体、蛋白酶—底物、同名蛋白—RNA来源定位分别处理；相关性图不能升级成受体活性或器官功能。

能从正确结果表重绘时，不重新拟合模型。需要重算时明确是样本、归一化、统计还是绘图层改变；不能为了视觉效果改结果。

## 模型页和讲述备注

模型页回答三个问题：**要建立什么状态？怎样建立？拟评价哪些表型？**区分引用已有模型与本项目拟开展构建。细胞类型选择有用，但不能代替造模状态。只有用户需要时才展开分组矩阵、试剂浓度和完整Protocol。

正文保留核心结论、必要限制和导师要讨论的选择。备注包括：一句结论、读图顺序、关键数字及分母、常见追问、原文图号/页码、数据/脚本出处。用户未读完整输出时尤其需要这些内容。备注不能成为隐藏重大不确定性的地方，也不自动扩展成另一份长报告。

将补充页移到正文时，同步取消“备份”标记、更新章节编号和导航，保留其发表状态；不要因为进入正文就改变证据级别。

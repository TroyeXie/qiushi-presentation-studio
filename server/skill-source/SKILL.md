# TroyeXie_PPT_Style

把素材组织为**有事实支撑、能够讲述、视觉协调的汇报**。这套Skill包含制作方法和可选模板参数，不是个人经历库、科研结论库或随意套用的固定页数模板。

## 规则优先级

**用户本轮明确要求 > 最新认可文件及指定模板 > 明确选用的模板profile > 本Skill通用建议。**局部修订以最新文件为基线，不重新引入已删除的段落、页码、图表或并行课题。时长与页数独立维护，不把取消页数限制理解为同时取消时长限制。

具体的导航14 pt、参考文献9 pt及内容区坐标，仅属于可选的[蓝白学术模板配置](profiles/clinical-academic.json)。不要在未知模板上自动套用。用户提供字体时先核对字体实际family与字形；仅文件名相同不能证明渲染正确。原文截图保留原字形，用户指定的正文/新图字体不适用于改写原件。

## 开始前的最小盘点

实读最新文件和参考页，确认受众、核心问题、页数/时长、保留内容、输出格式和素材权限。制作轻量的私有素材表：来源、证明什么、实际阅读/分析层级、必须保留区域、拟用页面。不要仅凭上轮“已完成”声明推断当前文件存在。

把反馈分为全局格式、指定页改文、换图、链接范围、删并移页。使用“原页—新页”映射；文件内的slide编号不一定等于演示顺序。先处理不依赖缺件的部分，只询问影响正确性或真实交付的缺项。

## 页面构造

1. **一页一个可复述的命题。**先确定观众应记住什么，再选择图片和数据；不为每页有图而塞装饰图。
2. **事实与价值连续。**成长/实践汇报说明行动、个人贡献和成果，再提炼价值；学术汇报区分文献已有结果、本项目分析与下一项问题。
3. **以真实素材为主体。**论文原图、现场照片、官方材料等保留证据身份；自绘示意和重排摘要不能伪装成截图。
4. **少而具体的文字。**直接说明疾病、细胞、操作及结果，避免只写“来源影响活化”等抽象话。保留关键推断的不确定性，不将设备准备和普通页面写成防御性说明。
5. **相关元素整体对齐。**图片、图注和小标题视作一组，数值与单位视作一组；同时检查几何边界与真实字形的视觉中心。
6. **主次不等于删数据。**主线结果连续展示；探索分支压缩盘点或移至备份，完整结果可保留在私有工作区。不要按文件夹编号依次汇报。

## 学术来源与超链接

学术资料页用完整题名、期刊、年份和数据源；正文用听众能理解的论文身份，不以私有D编号代替。每张引用原图有一句清楚图注，详细图号与页码放备注。

- 原文图：`完整题名 | 期刊, 年份.`
- 本项目再分析：`数据来源：完整题名 | 期刊, 年份.`
- 官方材料：`官方来源：资料题名 | 机构或平台, 年份/核查日期.`

**仅期刊/机构/平台名可点击，且加粗、无下划线。**题名、前缀、年份、标点和发表状态不链接。用独立文字run创建锚点，并检查形状级点击动作，不能只改可见颜色。全文来源与有限点击范围同时保留。

原文、Source Data再绘、本项目计算、预测和计划分别标识。研究计划不当作完成结果；Reviewed Preprint/v2等状态不因移入正文而删除。模型页说明“什么状态、怎样建立、评价哪些表型”，不是只列细胞名称。

## 视觉与交付

默认优先华文楷体、浙大蓝#074591；当前模板和明确字体要求优先。先用最长同级标题验证容纳，保持同级字号一致。去掉句中不必要的强制换行；优先调整可用宽度或精炼文字，不逐页随机缩字。避免末行只剩一两字，必要时重写同义短句。

标题与分隔线左对齐；用户指定时，正文右边界对齐校标右边界，引用末行与页码底部形成视觉对齐。原图按比例放置，保留标尺、子图编号、轴和证据字段；新多子图按阅读顺序标A–F等。

重排页面后同步检查页码、章节编号、导航、备注、内部跳转和PDF顺序。尽量只修改受影响的XML/对象，不用全页截图掩盖编辑能力丢失。

## 两层检查

可选运行只读工具：

```bash
python scripts/inspect_pptx.py presentation.pptx --output inventory.json
python scripts/lint_pptx_style.py presentation.pptx --profile profiles/clinical-academic.json
```

第二项仅在明确选用该profile时使用；精确链接校验可另传引用映射，见[模板参数说明](references/template-profile.md)。这些工具不能验证事实、所有继承样式、真实字体渲染、裁图或播放效果。

导出后重新打开/渲染最终文件：全页联系表看节奏，所有改动页放大检查，密集图与页底链接重点核验。PDF来自最终PPTX；必要时核对PDF真实点击矩形，不能仅检查PPT文字。只报告实际做过的测试。

## 保留与不继承

保留已确认的母版、图片、备注、媒体和有效结果；有科学意义的非显著结果不因不美观而删除。改图不自动重拟合模型，修改统计时单独说明。

不固定某人的成果、供者数字、分子通路、实验结论、老师名单、活动年月、页数或时长；不默认清空备注、自动播放、加背景音乐或脱敏。字体、logo、原始论文、私人分析、模板二进制和真实截图均不随公共仓库分发。只提交通用规范、无敏感信息的配置/代码及合成测试。

交付实际存在的PPTX；按用户需要提供PDF等。保留文本和表格可编辑，源索引与临时QA默认不加入成品。仓库写入需读回验证，下载链接需确认文件存在；未完成的事项不能在结尾写成完成。

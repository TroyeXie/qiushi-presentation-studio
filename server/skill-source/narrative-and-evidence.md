# 叙事与证据

用于从大量材料中建立主线、提升标题价值、核实成果和决定上屏信息。

## 从素材清单到汇报主线

素材齐全不等于叙事完整。先按汇报目标归并，再选择能够承载个人贡献、专业进展或集体成果的少数主线。可用“问题—行动—结果—意义”帮助梳理，但不强制每页或每套都套用四段。

把素材的两种优先级分开：用户明确指定必须纳入的图不可因主观审美删去；可选材料则根据证明力、画质、重复程度和页面任务择优。全局检查照片复用，优先不同场景；封尾呼应或明确要求复用时可以例外。

重要证据靠近对应论点。角色—现场—成果之间应能够一眼建立联系：证书证明荣誉，现场照片说明行动，正式通知说明接收状态，新闻页面说明报道。合影本身不自动证明奖项或职务。

## 标题的价值尺度

优先“领域/行动 + 具体成长或贡献”的标题，正式、凝练、可讲述。整组标题可采用平行句式和相近节奏；内容不合适时不硬凑对仗。

| 材料 | 可表达的价值方向 | 不能自动推出 |
|---|---|---|
| 课程与复习资料 | 专业知识基础、学习方法、朋辈共享 | 成绩排名、广泛使用或教学成果 |
| 论文、项目材料 | 对专业问题的研究积累、具体承担工作 | 项目负责人、独立完成、创新突破 |
| 会议发言及录取 | 学术表达、同行交流、在国内外展示本校专业研究 | 国际影响力、已完成未来会议发言 |
| 首诊与临床协作 | 诊疗规范、专业能力、沟通与责任 | 独立执业、治疗效果或患者总人数 |
| 学生工作与党务培训 | 理论素养、履职能力、协作服务 | 职务之外的组织权限或实际成效 |
| 志愿服务与社会实践 | 以专业所长回应需求、社会责任、理解基层 | 持续改变基层状况或政策影响 |
| 合唱、演出、艺术实践 | 校园美育、人文素养、团队协作 | 未获认可的艺术水平或个人获奖 |
| 运动与户外活动 | 规律锻炼、身心健康、团队参与 | 未测量的健康改善或竞技成绩 |

把“参加了很多活动”改为有明确贡献的表述；把“获得肯定”等口语换为可核实的荣誉或反馈。不要单纯替换成宏大词语。若没有证据支持结果，写角色、行动与学习，不虚构影响。

## 事实与状态

- 区分本人贡献与团队成果，参与、协助、组织、负责人、第一作者等不得互换。
- 区分投稿、录用、在线发表、编入卷期；区分录取发言、电子壁报接收、已完成会议报告。
- 区分拟申报、申报中、公示、正式获奖；一个活动环节获得认定，不扩大成整个项目获认定。
- 时间窗和统计口径服从当前确认。学年计入规则与客观日期可以不同：记录两者，不悄悄改写日期。
- 数据来自完整报告或台账时，不凭最醒目的一个比例概括全部结论。查分母、单位、有效样本与范围。中文汇报用清楚的单位，如“万字”，避免歧义缩写。
- 涉及日历统计时须已有当前访问授权；先定义事件、合并重复或跨午夜同一活动、排除取消/未发生条目。次数、场次、例数和独立人数分别统计，缺失值不猜。这个流程只在任务实际需要时启用。

## 使用原始证据

论文选实际含题名和作者的页面，不以 PDF 页序推定首页。完整保留原版字体和排版；课程复习资料的截图也是原件，不为了套风格替换其字体。

项目清单可展示表头和目标行，任务书可选首页或与本人成果相关的局部。远距离片段可组成“原文局部”视口，但不制造它们在原件中连续相邻的印象；说明可在相关图注或备注中保留。清单和文稿之间的归属关系须有材料依据。

报道优先显示平台标识、文章题名及相关内容。正式结果页可在证书尚未取得时作为替代证据，但名称应准确写为结果公示/通知截图。平台是否具有特定级别、转载是否等于原创报道，都需要依据。访问网页应服务于原图不清晰或核对事实，不无目的收集新素材。

## 精炼不等于删除边界

正文屏幕保留核心事实、贡献与必要限制；冗长过程、计算细节、来源索引可按场景置于备注或内部台账。若限制直接改变观众对成果的理解，不能只藏在不可见备注里。

不自动清空备注或脚注。用户明确要求删除时，仍保留必要的内部追溯记录；按提交规范需要引用时，精简美观必须让位于准确引用。

# 视觉语言与对齐

用于整套风格定义、参考迁移、封面设计及全局元素精修。指定模板优先；具体数值仅在选择相应[profile](template-profile.md)后应用。

## 实际看参考，区分模板、风格和事实

先看封面、普通内容页、密集图表页和结尾。模板决定保留结构，风格参考提供视觉方向，论文/照片等提供事实证据。不要只从文字提取推断布局，也不以近似重画替代用户要求保留的母版。

新建时先决定内容区和最长同级标题，再确定字号。续改时保留已经认可的背景、校标、导航、字号和图组；局部改字不重新设计整套页面。

## 字体、颜色和标志

无其他指定时，以华文楷体、浙大蓝 `#074591` 和清晰深色正文为起点。红金、蓝白、低饱和方案均可成立，需统一明度、强调方式和组件语言。颜色用于区分意义，不牺牲对比。

若用户指定STKAITI.TTF，应检查其内部family（常见STKaiti/华文楷体）、实际字形和导出渲染。新增中文、英文、数值和数据图是否全部使用该字体，按本轮要求；**论文截图保留原字形**。缺少上下标、希腊字母等字形时采用可验证的排版办法，不能悄悄输出缺字方框。仓库和交付包不附带字体文件。

同级标题、正文、表格、图注、引用与导航分别有统一字号。不要一页9 pt引用、另一页8.7 pt；不要以单页缩字代替合理排版。核心分子是否斜体按当前用户/学科规范，不由绘图软件默认决定。

校标使用用户提供的真实资源或模板已有对象，保持纵横比、正规颜色和透明背景。不生成替代标志，不将其随公共Skill分发。书法字体仅用于少量大标题，先检查可用性，不自动扩大到正文。

## 固定边界与光学对齐

明确四个参照：**标题左界、主体内容左/右界、引用区下界和页码**。在蓝白学术模板中：

- 标题左端与其下横线左端对齐；正文右端与右上校标右端形成同一垂直线。
- 多栏页面各自服从列宽，不把每一小框都机械拉到全页右界；主内容框遵循共同边界。
- 引用靠近页面底部，最后一行与页码形成底端视觉对齐，为页码预留右侧空间。
- 表格“简称/角色”类短字段通常居中；长题名保持便于阅读的对齐，不强迫全表居中。

母版/布局继承与本页对象都可能构成视觉边界。字形边距、透明图片留白和不同字重会使相同坐标看起来不齐，必须看渲染。

```text
列宽 = (内容宽度 - (列数 - 1) × 列间距) / 列数
图组水平中心 = 图片left + 图片width / 2
内容right = left + width
```

## 图组、图注与句子换行

图、小标题、图注作为一个整体比较宽度、高度、间距和视觉重量。并列组的小标题与各自图片共享水平中心；图注紧邻图片，组间距明显大于图—图注距离。

图注一句话直接概括核心发现，不在正文叠加“原文图：Fig.X（PDF第Y页局部）”等操作备注。英文panel标签、坐标、标尺和统计信息要保留。截图有白边时可裁去空白，但不能裁掉字、箭头或实验条件；边缘处多留少量安全空间。

句中换行优先交给文本框自然处理：扩展至已确定内容边界、去除多余内边距、精炼句子，再考虑全局字号调整。避免第二行只剩一两字；两行短句可按语义分组，并使首行略长。不能为了拉齐强加空格、压缩字距或改写数据。

少量大数字与类型名使用共同水平中心。对短数字图注无须重复长篇“点是样本”；但误差范围、加权分母或复杂图形语义必须能在页内/备注中查明。

## 导航、页码和顺序

导航使用受众能理解的分节，不用私有数据编号。项目名尽量保持一行，共同中心、均匀分布，当前章节文字与色块垂直居中。采用左侧导航时，其宽度与字号必须兼顾最长项目名。

按任务选择是否采用“1.1  标题”等编号，不自动给所有演示加小节。正文增加、删除、移动后同步更新逻辑页序、可见页码、章节号、当前导航及备注引用。

保留备份内容但移入正文时，去掉“备份”身份、设定当前小节和导航；发表状态或必要科学限定仍保留。页数改变不意味着时长要求自动改变。

## 引用文字和点击区域

完整题名在页脚，期刊或官方机构名加粗、无下划线；只链接名称，不链接题名、年份、前缀、标点或发表状态。具体结构见[学术汇报](academic-presentations.md)。

链接范围用真实run及PDF注释矩形检查，不能凭蓝色文字外观判断。隐藏的形状点击动作也可能让整块内容可点击。链接修改后保持其余字号、字重和文本不变。

## 科学图与多面板

数据正确时直接从既有表重绘，不为画图重拟合模型。来源图范围完整，正文可按明确规则精简，完整表另存。面板A–F按阅读顺序排列，同量纲适当共用坐标；不同研究保留各自单位与归一化说明，不靠颜色造成绝对量可比的错觉。

论文母版与投影页按不同阅读距离导出；不要把印刷用小字图整页塞进投影。新图尽量保留SVG/PDF矢量文本和图例；极密集点层可单独栅格化，不能把位图封装成SVG后宣称全部矢量。

## 封面、尾页与社会实践场景

真实场景可配统一蒙版保护对比，主体、旗帜和动作不被遮挡。封尾呼应标题几何和色彩，不一定复制同一信息。两行书法大字可按参考进行有限错落，但需先统一字距体系，再看笔画顶底与视觉重心，不随机跳字。

不固定某次封面文字、人物遮挡名单、背景音乐、字号或坐标。实践/成长类页面沿用[常见页面范式](layout-patterns.md)，不要被学术页脚规则机械覆盖。
